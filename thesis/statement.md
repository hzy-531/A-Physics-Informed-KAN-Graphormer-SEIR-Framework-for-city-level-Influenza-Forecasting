## 一、问题定义与研究目标 `[p.9-18]`

### 1.1 核心问题 `[p.9-11]`

多区域流感传播预测中存在三大挑战：

> **文献综述详见**：动力学模型 `[p.11-12]` | 数据驱动模型 `[p.12-13]` | 混合模型 `[p.13]` | KAN研究现状 `[p.13-14]` | 研究缺口 `[p.14-15]`

1. **非线性拟合 vs 可解释性**：纯数据驱动模型（LSTM/MLP）精度高但不可解释；动力学模型可解释但非线性拟合能力弱
2. **物理机制与数据驱动融合不足**：现有混合模型用静态权重平衡两类损失，难以适配疫情不同阶段
3. **空间关联刻画不准**：传统方法用地理距离/静态邻接矩阵，忽略了人口流动驱动的动态传播

### 1.2 研究目标 `[p.15-17]`

构建 KAN-Graphormer 混合模型，实现：
- 高精度预测 24 城流感日度病例
- 同时输出 β(t)、γ(t)、contact(t)、Rt 等流行病学参数
- 通过注意力权重和 B 样条曲线提供可解释性
- 捕捉南北方区域传播差异

## 二、理论支柱（三大基石）`[p.19-26]`

### 2.1 传染病动力学：从 SIR 到元种群 SEIR `[p.19-21]`

> SIR 经典模型 `[p.11]` → SEIR 引入潜伏期 `[p.19-20]` → 元种群 SEIR `[p.20-21]` → 反应-扩散-漂移 PDE `[p.21]`

**元种群 SEIR 方程**（城市 i）：
- dSi/dt = μNi - βi(t)·(Si·Ii)/Ni - μSi + Σ(mji·Sj - mij·Si)
- dEi/dt = βi(t)·(Si·Ii)/Ni - (σ+μ)Ei + Σ(mji·Ej - mij·Ei)
- dIi/dt = σEi - (γi(t)+μ)Ii + Σ(mji·Ij - mij·Ii)

> `[p.20-21]` 公式(2-5)~(2-7)。其中 mij 为城市 i→j 的人口流动率，用四阶龙格-库塔法离散求解。

**反应-扩散-漂移方程**（连续视角）：
```
∂I/∂t = D·∇²I + β·S·I/N - γI + v·∇I
        扩散项    反应项    恢复项   漂移项
```

> `[p.21]` 公式(2-8)

### 2.2 空间建模：改进的 Graphormer `[p.22-24]`

**GNN 基础** `[p.22]` → **Graphormer 三大编码改进** `[p.22-23]` → **Gated TCN** `[p.23-24]`

| 编码类型 | 原始方案 | 本文改进 | 原因 |
|---------|---------|---------|------|
| 中心度编码 | 向量加法 | 拼接+投影 `[xi‖z_deg⁻‖z_deg⁺]·W_proj` | 避免特征对消 |
| 空间编码 | 最短路径距离(SPD) | 扩散距离 d_diff | 人口流动 ≠ 地理距离 |
| 边编码 | 边特征嵌入 | 动态邻接矩阵 Aij(t)·W_E | 实时感知封城等管制 |

注意力分数：
```
C_attn_ij = (hi·WQ)(hj·WK)^T / √dk  -  α·d_diff(i,j)  +  ε_ij
                                       ↑扩散距离偏置    ↑边编码
```

门控密集连接防止过平滑：`H_S = H_S⊙σ(H_S) + H_D⊙(1-σ(H_S))`

### 2.3 非线性映射：KAN (Kolmogorov-Arnold Networks) `[p.24-25]`

**KA 表示定理** `[p.24]` → **B 样条参数化** `[p.24-25]` → **小样本权衡** `[p.25]`

**核心差异**：MLP 激活函数在节点上（固定），KAN 激活函数在边上（可学习）

```
MLP:  节点 = σ(W·x + b)       ← 固定激活（ReLU/Sigmoid）
KAN:  边   = φ(x) = w_b·SiLU(x) + w_s·Σ c_i·B_i(x)
               基函数分支           B样条可学习分支
```

> `[p.24-25]` 公式(2-15) | 残差KAN层公式(4-6)见 `[p.40]`

**Kolmogorov-Arnold 定理** `[p.24]` 公式(2-14)：
```
f(x₁,...,xₙ) = Σ_{q=1}^{2n+1} Φ_q( Σ_{p=1}^n φ_{q,p}(x_p) )
```
任意多元函数 = 有限个单变量函数的加法组合 → 学习 1D 函数比学习高维函数容易

**B 样条局部支撑性**：调整控制点 ci 只影响局部区间 → 训练稳定、可微调

**重力模型重构流量** `[p.25-26]` → **扩散距离计算** `[p.26]`

## 三、模型架构：四阶段信息流 `[p.27-35]`

### 3.1 总体框架 `[p.35-36]`

```
输入 X∈R^{N×F×Tin}, A∈R^{N×N×Tin}
  │  N=24城市, F=16特征, Tin=7天回看窗口
  ↓
[阶段1] Gated TCN (时序特征提取) `[p.37-38]`
  │  扩张因果卷积(d=1,2) + 双分支门控(tanh⊙sigmoid)
  │  并行计算, 感受野可控, 自适应过滤噪声
  ↓ H_T ∈ R^{N×H}
[阶段2] 改进 Graphormer (空间依赖建模) `[p.38-40]`
  │  拼接式中心度 + 扩散距离偏置 + 动态边编码
  │  2层多头注意力 + 门控密集连接
  ↓ H_S ∈ R^{N×H}
[阶段3] KAN 模块 (非线性映射) `[p.40]`
  │  B样条激活替代MLP + 残差连接
  │  H_K = LayerNorm(H_S + g·KAN(H_S)), g初始=0
  ↓ H_K ∈ R^{N×H}
[阶段4] 多任务解码头 `[p.40-41]`
  ├─ case_head: Softplus → 预测病例 ŷ∈R^{N×Tout}  (Tout=3天)
  ├─ beta_head:  Sigmoid×0.5+0.1 → β∈[0.1,0.6]
  ├─ gamma_head: Sigmoid×0.2+0.14 → γ∈[0.14,0.34] (3~7天)
  └─ contact_head: Sigmoid×1.5+0.1 → contact∈[0.1,1.6]
```

### 3.2 损失函数（多任务联合优化）`[p.41-42]`

```
L = L_data + λ₁·L_physics + λ₂·L_reg

L_data:   Huber Loss (δ=1.0) — 抵抗疫情数据噪声/异常值
L_physics: SEIR PDE 残差 L2 范数 — 物理一致性约束
L_reg:    L1+L2 正则化
```

### 3.3 课程学习：三阶段动态权重 `[p.42]`

| 阶段 | Epoch | λ₁ 物理权重 | 策略 |
|------|-------|------------|------|
| 探索期 | 0~10 | 0.001 | 几乎纯数据驱动，学习统计规律 |
| 介入期 | 11~30 | 线性增至 0.03 | 物理约束逐渐增强 |
| 锁定期 | 31~150 | 0.03 | 高物理惩罚 + KAN正则化剔除冗余 |

解决 PINN "正则化溢出" 问题：初始阶段施加等权物理惩罚会导致网络无法同时拟合数据+满足方程。

### 4.2 关键预处理 `[p.30-32]`

1. **PCHIP 降尺度** `[p.30-31]`：省级月度病例 → 城市日度序列（保形分段三次 Hermite 插值，公式(3-1)，保证非负+单调）
2. **重力模型重构流量** `[p.25, p.31]`：`F_ij = G·Pi^α·Pj^β / dij^γ`，公式(2-16)，将无量纲迁徙指数 → 绝对人口流量
3. **扩散距离** `[p.26, p.31]`：替代地理距离，公式(2-17)，基于随机游走概率分布的加权差异
4. **防泄露归一化** `[p.32]`：训练集时间切片内拟合 scaler，禁止未来信息泄露

### 5.1 两种数据划分 `[p.33, p.44]`

| 方案 | 划分方式 | 目的 |
|------|---------|------|
| 时序划分 (Chronological) | 前60%训练 + 中20%验证 + 后20%测试 | 模拟真实预测场景，检测分布外泛化 |
| 随机划分 (Random) | 70%/15%/15% 随机打乱 | 同分布下的理论上限（对照） |

> **关键**：时序划分中测试期正值封城后疫情下降阶段 → 数据分布偏移 → 对模型泛化能力的严峻考验

## 六、核心实验结果 `[p.44-57]`

### 6.1 时序划分下性能排名 `[p.46-48，表5-1]`

| 排名 | 模型 | R² | RMSE | MAE | 核心发现 |
|------|------|-----|------|-----|---------|
| 1 | KAN_Only | 0.9465 | 1.782 | 1.271 | 小样本下B样条泛化最强 |
| 2 | MLP_Baseline | 0.9436 | 1.830 | 1.301 | 简单模型在小数据有优势 |
| 3 | Full_KAN_Graphormer | 0.9432 | 1.836 | 1.296 | **精度+可解释性最佳平衡** |
| 4 | M_Graphormer_Baseline | 0.9413 | 1.867 | 1.333 | MLP非线性拟合略逊KAN |
| 5 | NoPhysics_KAN_Graphormer | 0.9320 | 2.009 | 1.401 | 去掉物理约束 R² 跌 ~1.2% |
| 6 | GAT_Baseline | 0.9248 | 2.113 | 1.467 | 24节点小图注意力引入噪声 |
| 7 | LSTM_Baseline | 0.8993 | 2.444 | 1.693 | 66天短序列训练困难 |

### 6.2 物理参数反演（Full_KAN_Graphormer）`[p.50-52]`

| 参数 | 均值±标准差 | 流行病学解读 |
|------|------------|------------|
| β (传播率) | 0.487 ± 0.081 | 封城后传播减弱，符合先验范围 |
| γ (恢复率) | 0.240 ± 0.005 | 约 4.2 天恢复期 |
| contact (接触修正) | 0.534 ± 0.092 | 干预下接触强度降低 ~50% |
| Rt (有效再生数) | 1.011 ± 0.244 | 接近 1.0，疫情受控于阈值附近 |
| Rt ∈ [0.5, 2.0] 比例 | 93.06% | 绝大多数估计值流行病学合理 |

### 6.3 区域异质性发现 `[p.52-53]`

- **封城效应**：封城城市 contact=0.353, Rt=0.593；非封城 contact=0.560, Rt=1.070
- **南北差异**：南方 β=0.561, Rt=1.168 vs 北方 β=0.399, Rt=0.825（p<0.001）
- **相关性**：供暖标识与 β 强负相关 (r=-0.633)，干燥环境可能抑制病毒传播

### 6.4 随机划分的警示 `[p.49-50]`

随机划分下 LSTM 最高 (R²=0.654)，Full 模型仅 0.454。说明：
- 随机划分可能引入空间维度数据泄露（图网络利用同时段其他城市信息）
- 时序划分才是检验真实预警能力的可靠基准

### 6.5 可解释性分析 `[p.53-55]`

- **注意力机制** `[p.53-54]`：识别跨区域传播关键路径（深圳→厦门、深圳→宁波、重庆→宁波等），呈现以上海/北京/广州/深圳为核心的 hub-spoke 结构
- **KAN 激活函数可视化** `[p.55-56]`：β 头的 B 样条曲线呈非对称指数形态，病例预测头呈先饱和后衰减的非线性形态——无需人工预设即可自主适配最优映射

### 6.6 残差诊断与稳健性 `[p.56-57]`

残差均值=-0.3132，偏度=-0.1358，峰度=0.3388，Durbin-Watson=1.0811。

## 七、创新点与方法论贡献 `[p.59]`

1. **KAN + Graphormer 融合架构**：首次将 KAN 引入图 Transformer 的传染病预测，用 B 样条激活替代 MLP 固定激活，提升非线性表征+可解释性
2. **多任务动态平衡**：Huber Loss + 课程学习 + 逆 Sigmoid 初始化 + 生物限幅，解决小样本 PINN 的正则化溢出
3. **时序 vs 随机双验证范式**：揭示随机划分下空间信息泄露导致虚假高分的隐患，为时空预测模型评估提供方法论基准
4. **扩散距离空间偏置**：以人口流动网络替代地理距离，精准刻画跨区域传播关联

## 八、局限与展望 `[p.59-60]`

| 局限 | 改进方向 |
|------|---------|
| 66天窗口无法覆盖跨年度季节性 | 接入跨多波次的长序列数据 |

| 仅 24 城、单一流感季 | 扩展城市范围与多流感季验证 |

## 九、与 KAN 原始论文 (Liu et al., 2024) 的关系 `[p.13-14, p.24-25]`

本文借鉴 KAN 原始论文的核心思想：
- **Kolmogorov-Arnold 表示定理**：多元函数 → 单变量函数叠加
- **B 样条参数化**：`φ(x) = w_b·SiLU(x) + w_s·Σ c_i·B_i(x)`
- **可解释性优势**：可视化学习到的激活函数形态

本文的 **差异化应用**：
- 将 KAN 嵌入 Graphormer 中替代 MLP（非独立使用）
- 与 SEIR 物理方程耦合（非纯数据驱动）
- 应用于传染病时空预测（非函数拟合/PDE求解）
